# Plan #3

Intent as read: a play-book (the decision procedure) and its run-book (the steps) that countersign-system
runs to verify its own integrity, strictly level by level — L1 unit-test code, L2 integration-test code,
L3 unit-invariant inference, L4 system-invariant inference — each level gating the next.

## Design
Gate: level N runs only when N-1 passed. A failure stops the run, is reported as found (detect, don't
dispose) and escalates as one explicit counter-prompt; nothing is repaired inside a diagnostic. Every
step is read-only; the one write is the diagnostic record, `agent-corpus/audits/<date>-self-diagnostic.md`.
Order is cost and confidence: cheap mechanical proof first, so inference budget is never spent on a
broken build.

| level | what is verified | how | mode (CIM) | pass |
|---|---|---|---|---|
| L1 unit-test code | each module's own tests | `dyad check --tests <root>` over the tests classified `unit` | automatic | every unit test OK |
| L2 integration-test code | modules together: scratch-repo installs, the four-zone end-to-end test, guards on the live tree, transaction guards, the evidence block | the tests classified `integration`, then `dyad check --guards` and `dyad check --evidence` | automatic | all OK, evidence block green, its sha recorded |
| L3 unit-invariant inference | does each unit's invariant list actually capture its contract? | first the mechanical invariant pass (`[invariant]` lines, all `ok`); then the Agent reads a rotating sample of K units (module docstring and owning Rule vs its `INVARIANTS` and tests) and judges coverage | implicit | no uncovered contract clause; each gap is a proposed invariant (a `backlog` row), not a fix |
| L4 system-invariant inference | properties of the whole system | a fixed list: CIM I1–I8 (the projector checks I1, I7, I6; the rest by reading); ledger ↔ provenance faithfulness (a sample, beyond the count check); zone and profile agree with the host (`infrastructure/HOST.md` vs observed); Rule-5 coherence (a rotating pair sample); hand-over criteria H1–H5 status; the sentinel | implicit | no violated invariant; each finding is an escalation |

Budget: L3/L4 inference is bounded per run (K units, P rule pairs), with a rotation cursor kept in the
record so successive runs cover everything — the client's inference-budget concern (#143) made explicit.
